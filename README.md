## 🌟 Overview

**BIMSpace Digital** bridges the gap between complex architectural design and seamless client presentation. Built for architects, civil engineers, and turnkey builders, it transforms static blueprints and bulky PDF drawings into an interactive, cloud-hosted digital twin accessible on mobile, tablet, and site laptops.

### 🏛️ Featured Project: Patil Residence - Executive Villa Twin
- **Client:** Er. Rameshwar & Sunita Patil
- **Location:** Baner Hills, Pune, Maharashtra
- **Total Area:** 3,850 Sq.Ft (G + 1 + Terrace Solar Deck)
- **Turnkey Budget:** ₹1.48 Cr (Civil + Premium Finishes + Solar)
- **Principal Architect:** Ar. Dnyaneshwar Adagale (BIMSpace Digital & Architecture)

## 🚀 Key Features

| Feature | Technical Implementation | Client & Site Benefit |
| :--- | :--- | :--- |
| **Interactive 3D WebGL Engine** | Three.js with soft shadow rendering, dynamic sunlight simulation (Day / Golden Hour / Night), and layer isolation. | Full spatial immersion into volume and cantilevers before casting slabs. |
| **2D Vector Blueprint Viewer** | Scalable SVG blueprint engine with pan/zoom, layer toggles, furniture layout, and metric dimension lines. | Clean, high-resolution drawing access on site without PDF clutter. |
| **Material & BOQ Specifications** | Granular Bill of Quantities categorized into Civil, Architectural Finishes, and Smart Home automation with live unit rates. | 100% transparency in structural steel (Tata Tiscon 550D) & cement grades. |
| **Site Progress Milestones** | Interactive milestone tracker with stage completion percentage, lab cube test verification, and site audit logs. | Remote progress monitoring for clients, reducing on-site coordination friction. |
| **Encrypted Document Vault** | One-click access to PMC sanctioned drawings, structural calculations, and geotechnical SBC certificates. | No misplaced physical drawings on dusty construction sites. |
| **Smart Expiry Counter** | 1-Year cloud hosting status indicator with direct renewal trigger. | Premium SaaS infrastructure model for architecture firms. |

## 🛠️ Technology Stack

- **Frontend Core:** React 19 + TypeScript + Vite
- **3D Graphics Engine:** Three.js (WebGL, Tone Mapping, Directional Shadow casting)
- **Styling & Theme:** Vanilla CSS Design System (Slate-950, Blueprint Cyan `#06B6D4`, Construction Gold `#F59E0B`)
- **Iconography:** Lucide React
- **Micro-Interactions:** Canvas Confetti & Glassmorphic Backdrop Blur

## 💻 Local Development & Deployment

1. **Clone repository:**
   ```bash
   git clone https://github.com/dnyaneshwaradagale5723/BIMSpace-Digital.git
   cd BIMSpace-Digital
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build production bundle:**
   ```bash
   npm run build
   ```

## 🌐 Instant Deployment to Live Hosting

To host this live on the internet with a custom link:

### Option A: Vercel (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import repository `dnyaneshwaradagale5723/BIMSpace-Digital`
3. Click **Deploy**. Vercel will automatically build the Vite project and provide your live `https://bimspace-digital.vercel.app` URL.

### Option B: Netlify
1. Connect `dnyaneshwaradagale5723/BIMSpace-Digital` on Netlify.
2. Build command: `npm run build`, Publish directory: `dist`.
